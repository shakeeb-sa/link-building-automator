1. The Filling Engine (Data Entry)
Strategies for filling forms instantly.

Shortcut	Feature Name	What It Does
Click (4x)	God Mode (Smart Fill)	The primary trigger. Fills all empty text inputs, checks checkboxes, and auto-opens file uploaders.
Ctrl + Click (4x)	Observer Sequence	Triggers the "Smart Dropdown" logic. Selects Country → Watches DOM → Selects Region → Watches DOM → Selects City. Zero wait time.
Shift + Click (4x)	Force Fill (Inputs)	"Cleanup Mode." Scans for any empty text fields remaining and fills them with generated Fake Data (prevents validation errors).
Ctrl + Shift + Click (4x)	Force Fill (Selects)	"Cleanup Mode." Scans for any unselected dropdowns and picks a random valid option.
Focus on Input	Context Picker	Shows a floating menu to manually inject specific data (e.g., just "Email" or just "Fake Name") into a single field.
